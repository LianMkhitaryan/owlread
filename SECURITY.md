# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them privately through GitHub: go to the **Security** tab of this repository and choose **Report a vulnerability**.

Include what you found, how to reproduce it, and which browser and Owlread version you used. We aim to reply within 7 days.

## Supported versions

Owlread is not released yet. Once it is, only the latest version gets security fixes.
